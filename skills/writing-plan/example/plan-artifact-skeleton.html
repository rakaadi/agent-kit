Implementation plan · Illustrative skeleton

Preserve missing readings in CSV exports

Goal

Export a missing reading as an empty cell and a measured zero as 0.

Architecture

Define both cases in the CSV contract. The existing exporter owns the conversion from a nullable reading to a cell. Import and storage keep their existing representations.
